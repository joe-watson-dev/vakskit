VaksKit

Understand any web page.

VaksKit is a Chrome extension that reads the page you are on and gives you results you can use in your own project.

  • SEO report and export: JSON, TypeScript or HTML <head> tags
  • Page to Markdown: the main content, clean and ready to copy
  • Fonts and type scale: every font, where it is used, and the CSS to reuse it
  • Markdown to HTML: preview, copy or download

Everything runs in your browser. No account, no tracking.
